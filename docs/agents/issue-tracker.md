# Local implementation tracker
Implementation tickets are tracked in `.scratch/merchant-pos/issues/` until GitHub write access is connected. No external issue is implied. Status: ready-for-agent, in-progress, completed, blocked. Product decisions: docs/product/merchant-direction.md; architecture: docs/adr/.
